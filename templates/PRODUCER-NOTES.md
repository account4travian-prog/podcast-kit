# Producer Notes (generic template)

Standing rulings from the producer, in the order they were made.
The kit's `doctor` command pins the hash of this file in SOURCES.json;
when it changes, check whether any ruling alters a rule a speaker,
watcher or auditor follows, update the prompts if so, and re-accept.
